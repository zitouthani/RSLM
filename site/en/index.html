The project

A document assistant you can inspect.

Document-grounded answers use vector retrieval, reranking, and a selected context. Sources are displayed with their documents and pages.

01

Search your PDFs

Load an authorized corpus, index its passages, and retrieve information with document references.

02

Traceable RAG pipeline

Inspect retrieved candidates, ranking scores, the context sent to the model, and the sources attached to an answer.

03

Corpus management and backups

Manage documents from the interface and use local backup and restore tools.

                    └→ reranking → context → cited answer

FAQ

Before running RSLM.

Does the website host the chatbot?

No. GitHub Pages serves the static website only; the API, Ollama, and documents run locally.

Are PDFs or models included?

No. Add only a corpus you are authorized to process. Documents, indexes, and downloaded model weights are not included in the repository.

Which installation path should I choose?

The local path runs the API and UI from Python. Docker Compose containerizes the API and Qdrant, while Ollama remains on the host. Read the guide before choosing.

Local demo, not a hosted public service.

This website presents the source code; it does not host a chatbot or document corpus. Do not expose the API to untrusted networks without authentication, HTTPS, access controls, and resource limits. PDFs and indexed data are not included.
