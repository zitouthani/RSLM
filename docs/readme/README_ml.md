# RSLM

RSLM ഒരു ഓപ്പൺ സോഴ്‌സ് പ്രാദേശിക ഡോക്യുമെന്റ് അസിസ്റ്റന്റാണ്. ഇത് റിട്രീവൽ ഓഗ്മെന്റഡ് ജനറേഷൻ (RAG) ഉപയോഗിക്കുന്നു. Streamlit, FastAPI, Qdrant, Sentence Transformers, Ollama എന്നിവയാണ് ഇതിൽ സംയോജിപ്പിച്ചിരിക്കുന്നത്.

**മറ്റ് ഭാഷകൾ:** [ഭാഷാ സൂചിക](README.md) · [ഫ്രഞ്ച് പൂർണ്ണ ഡോക്യുമെന്റേഷൻ](../../README.md) · [ഇംഗ്ലീഷ് പൂർണ്ണ ഡോക്യുമെന്റേഷൻ](../../README.en.md)

## സവിശേഷതകൾ

- ഉപയോഗിക്കാൻ അനുമതിയുള്ള PDF-കൾ തിരയുകയും ഡോക്യുമെന്റും പേജ് നമ്പറും ഉദ്ധരിക്കുകയും ചെയ്യുന്നു.
- പ്രാദേശിക ഡോക്യുമെന്റ് ശേഖരം, സംഭാഷണ ചരിത്രം, ബാക്കപ്പുകൾ എന്നിവ കൈകാര്യം ചെയ്യുന്നു.
- തിരികെ ലഭിച്ച ഫലങ്ങൾ, മോഡലിന് നൽകിയ സന്ദർഭം, ഉത്തരത്തിന്റെ ഉറവിടങ്ങൾ എന്നിവ പരിശോധിക്കാം.
- നിങ്ങളുടെ സ്വന്തം ഡാറ്റാസെറ്റുകൾ ഉപയോഗിച്ച് തിരച്ചിലും ഉത്തരങ്ങളും വിലയിരുത്താം.

## തുടക്കം

Python 3.11 അല്ലെങ്കിൽ അതിനുശേഷമുള്ള പതിപ്പും പ്രാദേശികമായി പ്രവർത്തിക്കുന്ന Ollamaയും ആവശ്യമാണ്. Docker Compose-വും തിരഞ്ഞെടുക്കാം. വിശദമായ ഘട്ടങ്ങൾക്ക് [ഫ്രഞ്ച് ഇൻസ്റ്റലേഷൻ ഗൈഡ്](../guide-reproduction.md) അല്ലെങ്കിൽ [ഇംഗ്ലീഷ് ഇൻസ്റ്റലേഷൻ ഗൈഡ്](../reproduction-guide.en.md) കാണുക.

RSLM പ്രാദേശിക ആപ്ലിക്കേഷനാണ്; ഹോസ്റ്റ് ചെയ്ത പൊതുസേവനമല്ല. റിപ്പോസിറ്ററിയിൽ PDF-കൾ, മോഡൽ വെയ്റ്റുകൾ, ഇൻഡെക്സുകൾ എന്നിവ ഉൾപ്പെടുത്തിയിട്ടില്ല. നിങ്ങൾക്ക് ഉപയോഗാനുമതിയുള്ള ഡോക്യുമെന്റുകൾ മാത്രം പ്രോസസ് ചെയ്യുക; `.env` രഹസ്യങ്ങളോ സ്വകാര്യ ഡാറ്റയോ commit ചെയ്യരുത്.

സോഴ്‌സ് കോഡ് MIT ലൈസൻസിലാണ്; ഉപയോക്തൃ ഡോക്യുമെന്റുകൾക്കും മൂന്നാംകക്ഷി മോഡലുകൾക്കും ഈ ലൈസൻസ് ബാധകമല്ല. ഈ സംക്ഷിപ്ത വിവർത്തനം മാതൃഭാഷക്കാരൻ സ്വതന്ത്രമായി പരിശോധിച്ചിട്ടില്ല.
