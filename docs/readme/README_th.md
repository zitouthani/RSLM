# RSLM

RSLM คือผู้ช่วยค้นหาความรู้จากเอกสารแบบโอเพนซอร์สที่ทำงานในเครื่อง และใช้ RAG (การสร้างข้อความเสริมด้วยการค้นคืนข้อมูล) โดยผสาน Streamlit, FastAPI, Qdrant, Sentence Transformers และ Ollama

**ภาษาอื่น:** [ดัชนีภาษา](README.md) · [เอกสารฉบับเต็มภาษาฝรั่งเศส](../../README.md) · [เอกสารฉบับเต็มภาษาอังกฤษ](../../README.en.md)

## คุณสมบัติ

- ค้นหา PDF ที่ได้รับอนุญาตให้ใช้ พร้อมอ้างอิงเอกสารและเลขหน้า
- จัดการคลังเอกสารในเครื่อง ประวัติการสนทนา และข้อมูลสำรอง
- ตรวจสอบผลการค้นคืน บริบทที่ส่งให้โมเดล และแหล่งที่มาของคำตอบ
- ประเมินการค้นคืนและคำตอบด้วยชุดข้อมูลของคุณเอง

## เริ่มต้นใช้งาน

ต้องใช้ Python 3.11 ขึ้นไปและ Ollama ที่ทำงานในเครื่อง นอกจากนี้ยังเลือกใช้ Docker Compose ได้ ดูขั้นตอนโดยละเอียดใน[คู่มือติดตั้งภาษาฝรั่งเศส](../guide-reproduction.md)หรือ[ภาษาอังกฤษ](../reproduction-guide.en.md)

RSLM เป็นแอปพลิเคชันในเครื่อง ไม่ใช่บริการสาธารณะที่โฮสต์ไว้ ที่เก็บนี้ไม่มี PDF น้ำหนักโมเดล หรือดัชนี โปรดประมวลผลเฉพาะเอกสารที่คุณมีสิทธิ์ใช้ และอย่า commit ความลับใน `.env` หรือข้อมูลส่วนตัว

ซอร์สโค้ดใช้สัญญาอนุญาต MIT ซึ่งไม่ครอบคลุมเอกสารของผู้ใช้หรือโมเดลจากบุคคลที่สาม คำแปลฉบับย่อนี้ยังไม่ได้รับการตรวจทานอย่างอิสระโดยเจ้าของภาษา
