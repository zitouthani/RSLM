# RSLM

Το RSLM είναι ένας τοπικός βοηθός εγγράφων ανοιχτού κώδικα που χρησιμοποιεί παραγωγή με επαύξηση ανάκτησης (RAG). Συνδυάζει τα Streamlit, FastAPI, Qdrant, Sentence Transformers και Ollama.

**Άλλες γλώσσες:** [Ευρετήριο γλωσσών](README.md) · [Πλήρης τεκμηρίωση στα γαλλικά](../../README.md) · [Πλήρης τεκμηρίωση στα αγγλικά](../../README.en.md)

## Δυνατότητες

- Αναζήτηση σε PDF που επιτρέπεται να χρησιμοποιείτε, με παραπομπές σε έγγραφα και σελίδες.
- Διαχείριση τοπικού σώματος εγγράφων, ιστορικού συνομιλιών και αντιγράφων ασφαλείας.
- Έλεγχος των αποτελεσμάτων ανάκτησης, του πλαισίου που στέλνεται στο μοντέλο και των πηγών της απάντησης.
- Αξιολόγηση ανάκτησης και απαντήσεων με δικά σας σύνολα δεδομένων.

## Ξεκινώντας

Απαιτούνται Python 3.11 ή νεότερη έκδοση και τοπικά εκτελούμενο Ollama. Μπορείτε επίσης να επιλέξετε Docker Compose. Για τα αναλυτικά βήματα, δείτε τον [οδηγό εγκατάστασης στα γαλλικά](../guide-reproduction.md) ή [στα αγγλικά](../reproduction-guide.en.md).

Το RSLM είναι τοπική εφαρμογή και όχι δημόσια φιλοξενούμενη υπηρεσία. Το αποθετήριο δεν περιλαμβάνει PDF, βάρη μοντέλων ή ευρετήρια. Επεξεργαστείτε μόνο έγγραφα που έχετε δικαίωμα να χρησιμοποιείτε και μην κάνετε commit μυστικών του `.env` ή ιδιωτικών δεδομένων.

Ο πηγαίος κώδικας διατίθεται με άδεια MIT· αυτή δεν καλύπτει έγγραφα χρηστών ή μοντέλα τρίτων. Αυτή η συνοπτική μετάφραση δεν έχει ελεγχθεί ανεξάρτητα από φυσικό ομιλητή.
