# RSLM

RSLM یک دستیار اسناد متن‌باز و محلی است که از تولید افزوده با بازیابی (RAG) استفاده می‌کند. این پروژه Streamlit، FastAPI، Qdrant، Sentence Transformers و Ollama را ترکیب می‌کند.

**زبان‌های دیگر:** [فهرست زبان‌ها](README.md) · [مستندات کامل فرانسوی](../../README.md) · [مستندات کامل انگلیسی](../../README.en.md)

## قابلیت‌ها

- جست‌وجو در فایل‌های PDF مجاز و ارجاع به سند و شماره صفحه.
- مدیریت مجموعه اسناد محلی، تاریخچهٔ گفتگو و نسخه‌های پشتیبان.
- بررسی نتایج بازیابی، زمینهٔ ارسال‌شده به مدل و منابع پاسخ.
- ارزیابی بازیابی و پاسخ‌ها با مجموعه‌داده‌های خودتان.

## شروع کار

به Python 3.11 یا جدیدتر و Ollama در حال اجرا روی دستگاه محلی نیاز دارید. Docker Compose نیز گزینه‌ای دیگر است. برای مراحل کامل، [راهنمای نصب فرانسوی](../guide-reproduction.md) یا [راهنمای انگلیسی](../reproduction-guide.en.md) را ببینید.

RSLM یک برنامهٔ محلی است، نه یک سرویس عمومی میزبانی‌شده. مخزن شامل PDF، وزن مدل یا نمایه نیست. فقط اسنادی را پردازش کنید که اجازهٔ استفاده از آن‌ها را دارید؛ اسرار `.env` یا داده‌های خصوصی را به Git اضافه نکنید.

کد منبع تحت مجوز MIT است؛ این مجوز شامل اسناد کاربران یا مدل‌های شخص ثالث نمی‌شود. این ترجمهٔ کوتاه به‌طور مستقل توسط گویشور بومی بازبینی نشده است.
