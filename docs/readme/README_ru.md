# RSLM

RSLM — локальный помощник по документам с открытым исходным кодом, использующий генерацию с дополнением поиском (RAG). Он объединяет Streamlit, FastAPI, Qdrant, Sentence Transformers и Ollama.

**Другие языки:** [Список языков](README.md) · [Полная документация на французском](../../README.md) · [Полная документация на английском](../../README.en.md)

## Возможности

- Поиск по PDF, которые разрешено использовать, с указанием документов и страниц.
- Управление локальной коллекцией документов, историей чатов и резервными копиями.
- Просмотр найденных фрагментов, контекста модели и источников ответа.
- Оценка поиска и ответов на собственных наборах данных.

## Начало работы

Требуются Python 3.11 или новее и локально запущенный Ollama. Также можно использовать Docker Compose. Подробные инструкции приведены в [руководстве по установке на французском](../guide-reproduction.md) и [на английском](../reproduction-guide.en.md).

RSLM — локальное приложение, а не размещённый публичный сервис. В репозитории нет PDF, весов моделей и индексов. Используйте только документы, которые вам разрешено обрабатывать; не добавляйте в Git секреты из `.env` и личные данные.

Исходный код распространяется по лицензии MIT; пользовательские документы и сторонние модели ею не охватываются. Этот краткий перевод не проходил независимую проверку носителем языка.
