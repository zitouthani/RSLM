# RSLM

RSLM — локальний помічник із документів з відкритим кодом, що використовує генерацію з доповненням пошуком (RAG). Він поєднує Streamlit, FastAPI, Qdrant, Sentence Transformers та Ollama.

**Інші мови:** [Перелік мов](README.md) · [Повна документація французькою](../../README.md) · [Повна документація англійською](../../README.en.md)

## Можливості

- Пошук у PDF, які дозволено використовувати, з посиланнями на документи й сторінки.
- Керування локальною колекцією документів, історією розмов і резервними копіями.
- Перегляд знайдених фрагментів, контексту моделі та джерел відповіді.
- Оцінювання пошуку й відповідей на власних наборах даних.

## Початок роботи

Потрібні Python 3.11 або новіша версія та Ollama, запущений локально. Також можна використовувати Docker Compose. Докладні кроки наведено у [французькому посібнику зі встановлення](../guide-reproduction.md) та [англійському посібнику](../reproduction-guide.en.md).

RSLM — локальна програма, а не розміщений публічний сервіс. У репозиторії немає PDF, ваг моделей чи індексів. Обробляйте лише документи, якими маєте право користуватися; не додавайте до Git секрети з `.env` або приватні дані.

Вихідний код поширюється за ліцензією MIT; вона не поширюється на документи користувачів і сторонні моделі. Цей стислий переклад не проходив незалежної перевірки носієм мови.
