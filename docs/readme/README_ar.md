# RSLM

RSLM مساعد مفتوح المصدر للمستندات يعمل محلياً ويستخدم التوليد المعزّز بالاسترجاع (RAG). يجمع بين Streamlit وFastAPI وQdrant وSentence Transformers وOllama.

**لغات أخرى:** [فهرس اللغات](README.md) · [الوثائق الكاملة بالفرنسية](../../README.md) · [الوثائق الكاملة بالإنجليزية](../../README.en.md)

## الميزات

- البحث في ملفات PDF المصرح باستخدامها مع الإشارة إلى المستندات والصفحات.
- إدارة مجموعة المستندات المحلية وسجل المحادثات والنسخ الاحتياطية.
- فحص نتائج الاسترجاع والسياق المرسل إلى النموذج ومصادر الإجابة.
- تقييم الاسترجاع والإجابات باستخدام مجموعات بياناتك.

## البدء

يتطلب Python 3.11 أو أحدث وOllama يعمل محلياً. ويمكن اختيار Docker Compose أيضاً. راجع [دليل التثبيت بالفرنسية](../guide-reproduction.md) أو [بالإنجليزية](../reproduction-guide.en.md) للتعليمات الكاملة.

RSLM تطبيق محلي وليس خدمة عامة مستضافة. لا يحتوي المستودع على ملفات PDF أو أوزان النماذج أو الفهارس. عالج المستندات التي تملك حق استخدامها فقط، ولا ترفع أسرار `.env` أو البيانات الخاصة.

شفرة المصدر مرخصة بموجب MIT؛ ولا يشمل ذلك مستندات المستخدمين أو نماذج الجهات الخارجية. لم تتم مراجعة هذه الترجمة المختصرة بصورة مستقلة من متحدث أصلي.
