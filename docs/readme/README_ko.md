# RSLM

RSLM은 검색 증강 생성(RAG)을 사용하는 오픈 소스 로컬 문서 어시스턴트입니다. Streamlit, FastAPI, Qdrant, Sentence Transformers, Ollama를 결합합니다.

**다른 언어:** [언어 목록](README.md) · [프랑스어 전체 문서](../../README.md) · [영어 전체 문서](../../README.en.md)

## 기능

- 사용 권한이 있는 PDF를 검색하고 문서와 페이지를 인용합니다.
- 로컬 문서 코퍼스, 대화 기록, 백업을 관리합니다.
- 검색 결과, 모델 컨텍스트, 답변 출처를 확인합니다.
- 자체 데이터셋으로 검색과 답변을 평가합니다.

## 시작하기

Python 3.11 이상과 로컬에서 실행되는 Ollama가 필요합니다. Docker Compose도 선택할 수 있습니다. 자세한 단계는 [프랑스어 설치 가이드](../guide-reproduction.md) 또는 [영어 설치 가이드](../reproduction-guide.en.md)를 참조하세요.

RSLM은 로컬 애플리케이션이며 호스팅되는 공개 서비스가 아닙니다. 저장소에는 PDF, 모델 가중치, 인덱스가 포함되지 않습니다. 사용 권한이 있는 문서만 처리하고 `.env` 비밀 정보나 개인 데이터를 커밋하지 마세요.

소스 코드는 MIT 라이선스이며 사용자 문서나 타사 모델에는 적용되지 않습니다. 이 간략 번역은 원어민의 독립 검토를 받지 않았습니다.
