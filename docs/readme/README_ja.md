# RSLM

RSLM は、検索拡張生成（RAG）を利用するオープンソースのローカル文書アシスタントです。Streamlit、FastAPI、Qdrant、Sentence Transformers、Ollama を組み合わせています。

**他の言語：**[言語一覧](README.md) · [フランス語の完全版](../../README.md) · [英語の完全版](../../README.en.md)

## 機能

- 利用許可のある PDF を検索し、文書名とページ番号を引用します。
- ローカル文書コーパス、会話履歴、バックアップを管理します。
- 検索候補、モデルに渡すコンテキスト、回答の出典を確認できます。
- 独自のデータセットで検索と回答を評価できます。

## はじめに

Python 3.11 以降と、ローカルで動作する Ollama が必要です。Docker Compose も選択できます。詳しい手順は[フランス語の導入ガイド](../guide-reproduction.md)または[英語の導入ガイド](../reproduction-guide.en.md)を参照してください。

RSLM はローカルアプリケーションであり、公開ホスト型サービスではありません。リポジトリには PDF、モデルの重み、インデックスは含まれません。利用権限のある文書だけを処理し、`.env` の秘密情報や個人データをコミットしないでください。
